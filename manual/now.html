Introducción

N.I.C.O.L.E (Inteligencia Neuronal como Chef, Ofreciendo Experiencias de Aprendizaje) es una aplicación de escritorio pensada para ayudar a organizar y gestionar información de manera sencilla. Con una presentación clara y fácil de usar, permite ver, editar o eliminar datos sin complicaciones. La aplicación viene en un solo archivo que se puede usar en cualquier computador con Windows, sin necesidad de instalar programas adicionales.

💡 Consejo: Mantén tu copia de N.I.C.O.L.E actualizada para aprovechar mejoras y correcciones.

Requisitos

  • Computador con Windows 10 o 11
  • Conexión a internet
  • Cuenta de usuario con acceso completo al equipo

Instalación

⚠️ Importante: Abre el archivo de instalación como persona encargada del equipo para evitar errores.

Descarga el archivo enviado por correo y haz doble clic sobre el archivo llamado Nicole. Sigue estos pasos:

  1. Elige si deseas que esté disponible solo para ti o para todos los usuarios del equipo.
  2. Selecciona el idioma: español o inglés.
  3. Acepta las condiciones para continuar.
  4. Elige la carpeta donde se guardará la aplicación.
  5. Decide si deseas un acceso rápido en el escritorio.
  6. Haz clic en Instalar para completar.
ℹ️ Si tu programa de seguridad no permite la instalación, agrégalo a la lista de excepciones y vuelve a intentarlo.

Ingreso

Para comenzar a usar la aplicación:

  1. Escribe tu correo y contraseña.
    2. ℹ️ use los datos de inicio ,suministrados en los requisitos si es el primer ingreso
    ℹ️ en el primer ingreso se inica como Administrador, con el usuario admin
    ℹ️ se permite ingreso como usuario y como Administrador, pero primero se tiene que hacer el ingreso con los datos por defecto y luego crear un usuario ya sea estandar o Administrador
  2. Haz clic en Continuar.
  3. Verás la pantalla principal donde podrás trabajar con los datos permitidos.

Funciones principales

1. Elegir grupo de datos

Selecciona qué conjunto de información deseas ver desde una lista.

2. Buscar datos

Usa el cuadro de búsqueda para encontrar lo que necesitas.

3. Cambiar información

Haz doble clic sobre el dato que deseas editar.

4. Agregar información

Haz clic en Añadir para abrir una pantalla donde puedes escribir nuevos datos.

5. Eliminar información

Selecciona un dato y haz clic en Borrar. Se te pedirá confirmar antes de eliminar.

Guardar datos

Se pueden guardar los datos actuales en archivos de uso común (como hojas de cálculo o texto). También puedes elegir en qué carpeta guardarlos.

ℹ️ Para muchos datos, elige formatos más ligeros como texto plano.

Conclusiones

N.I.C.O.L.E ayuda a trabajar con información de forma clara, rápida y sin instalaciones complejas. Este manual te guía paso a paso para instalar, configurar y usar la herramienta sin necesidad de conocimientos técnicos.

Con buenos hábitos como guardar copias, revisar cambios y organizar bien los datos, esta aplicación puede ser un apoyo muy útil en tu día a día.

Solución de problemas

  • No puedo ingresar: Revisa tu conexión a internet y asegúrate de que el usuario y contraseña estén correctos.
  • La aplicación no abre: Intenta abrirla como responsable del equipo o reinstala el archivo.
  • No veo ciertos datos: Puede que no tengas permiso para verlos. Consulta con quien administra la aplicación.
  • Los cambios no se guardan: Revisa si tienes conexión o si puedes modificar los datos.
  • No puedo guardar los datos: Asegúrate de tener espacio en el equipo y que la carpeta elegida exista.
